# Site repo notes

Public repo for spencerscottsmith.com (preview: spencerscottsmith.rockofpages.com).
Hand-authored HTML, CSS and vanilla JS; no build step. The README covers pages,
data files, placeholders and deploy.

Planning notes, research, Spencer's feedback and the raw art kit are NOT here.
They live in `~/projects/spencerscottsmith-and-thecherokeeroses/` (its CLAUDE.md
has a "Resume here" checklist and the open items). Keep them out of this repo.

Rules: no em dashes in any prose; bump the `?v=` string on CSS, JS, icons and
replaced images when they change; verify locally before deploying; never commit
screenshots or the raw media.
